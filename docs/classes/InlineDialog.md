# InlineDialog

主窗口内的对话框表面，不创建原生窗口。

- **类型：** `public sealed class`，基类/实现：`ContentControl`。
- **主要方法：** `Activate`、`Close`、`ForceClose`、`Show`、`ShowDialog`。
- **源码注释：** A main-window surface. It owns no native window or independent message box.
- **源码：** [`InlineDialog.cs`](../../src/MCUGLauncher/InlineDialog.cs)。
