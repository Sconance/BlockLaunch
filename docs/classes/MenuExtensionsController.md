# MenuExtensionsController

把源码注册的菜单扩展接入各宿主页面。

- **类型：** `internal sealed partial class`，基类/实现：无。
- **主要方法：** `AttachExtensionButtons`、`AttachExtensionTabs`、`BuildMenuExtensionHosts`、`CreateMenuContent`、`MenuPageLabel`、`OpenMenuExtension`。
- **构造依赖：** `LauncherWorkspace workspace`。
- **源码：** [`MenuExtensions.cs`](../../src/MCUGLauncher/MenuExtensions.cs)、[`MenuExtensionsController.cs`](../../src/MCUGLauncher/Components/Shell/MenuExtensionsController.cs)。
