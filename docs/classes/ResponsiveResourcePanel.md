# ResponsiveResourcePanel

把分页资源结果排列为等宽自适应卡片。

- **类型：** `public sealed class`，基类/实现：`Panel`。
- **主要方法：** `ArrangeOverride`、`MeasureOverride`。
- **源码注释：** Arranges the small, paged resource result set into equal-width cards.
- **源码：** [`ResponsiveResourcePanel.cs`](../../src/MCUGLauncher/ResponsiveResourcePanel.cs)。
