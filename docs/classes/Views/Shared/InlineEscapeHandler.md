# InlineEscapeHandler

Esc 时先关闭展开的选择器。

- **类型：** `internal static class`，基类/实现：无。
- **主要方法：** `DismissSelector`。
- **源码注释：** Dismisses an expanded selector before Escape navigates away from its editor.
- **源码：** [`InlineEscapeHandler.cs`](../../../../src/MCUGLauncher/Views/Shared/InlineEscapeHandler.cs)。
