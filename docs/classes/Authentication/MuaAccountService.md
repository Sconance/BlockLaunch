# MuaAccountService

MUA 皮肤站账号的登录、资料读取与皮肤获取。

- **类型：** `public sealed class`，基类/实现：`IDisposable`。
- **主要方法：** `Dispose`、`Ensure`、`Forget`、`IsMuaConfiguration`、`Login`、`Metadata`、`Read`、`Session`。
- **构造依赖：** `HttpClient? client`、`string directory`。
- **源码：** [`MuaAccountService.cs`](../../../src/MCUGLauncher/Authentication/MuaAccountService.cs)。
