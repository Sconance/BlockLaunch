# MiniDownloadController

顶部迷你下载条、速度与暂停状态。

- **类型：** `internal sealed class`，基类/实现：无。
- **主要方法：** `BuildMiniDownloads`、`FormatDownloadSpeed`、`MiniDownloadRecord`、`RefreshMiniDownloads`、`SaveDownloadPause`、`ToggleMiniDownload`。
- **构造依赖：** `LauncherWorkspace workspace`。
- **源码：** [`MiniDownloadController.cs`](../../../src/MCUGLauncher/Components/MiniDownloadController.cs)。
