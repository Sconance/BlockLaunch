- **主要方法：** `CancelDownloadClick`、`ChangeDownload`、`EnqueueDownload`、`ExecuteDownload`、`PauseDownloadClick`、`PumpDownloads`、`QueueContent`、`QueuePackImport`。
- **构造依赖：** `LauncherWorkspace workspace`。
