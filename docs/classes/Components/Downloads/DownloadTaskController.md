# DownloadTaskController

下载任务页、任务状态操作与任务栏进度。

- **类型：** `internal sealed class`，基类/实现：无。
- **主要方法：** `BuildDownloadTaskCard`、`CancelMiniDownload`、`ChangeDownloadById`、`DownloadTaskPriority`、`DownloadTaskStatus`、`OpenDownloadTasks`、`RefreshDownloadTasks`、`RunAccountAction`。
- **构造依赖：** `LauncherWorkspace workspace`。
- **源码：** [`DownloadTaskController.cs`](../../../../src/MCUGLauncher/Components/Downloads/DownloadTaskController.cs)。
