# AppearanceController

应用背景与主题，并为独立 AppearanceSettingsPage 绑定偏好、保存、应用和文件选择操作。

- **类型：** `internal sealed class`，基类/实现：无。
- **主要方法：** `AccentColor`、`ApplyBackground`、`OpenAppearance`、`CreateAppearancePage`。
- **构造依赖：** `LauncherWorkspace workspace`。
- **源码：** [`AppearanceController.cs`](../../../../src/MCUGLauncher/Components/Experience/AppearanceController.cs)。
