# JavaManagerController

为 Java 页面提供偏好、保存和文件选择依赖；旧入口经 SettingsDialogPresenter 展示同一独立页面。扫描与选择表单位于 Views/Settings/JavaSettingsPage。

- **类型：** `internal sealed class`，基类/实现：无。
- **主要方法：** `OpenJavaManager`、`CreateJavaManagerPage`。
- **构造依赖：** `LauncherWorkspace workspace`。
- **源码：** [`JavaManagerController.cs`](../../../../src/MCUGLauncher/Components/Instances/JavaManagerController.cs)。
