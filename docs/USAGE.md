# 使用指南

1. 从 Releases 下载 Windows x64 EXE，直接运行。
2. 选择微软、离线或 MUA 登录；在线授权由本人完成。
3. 选择游戏目录，在展开的版本列表选择已安装实例。其他版本进入“下载”获取。
4. 点击启动；实例旁的设置入口管理模组、存档与导出。
5. Java 无法匹配时，进入 Java 管理扫描或手动选择。

资源可保存到独立下载目录，下载资源不等于已安装到实例，请按入口选择目标。

升级时关闭启动器并替换 EXE，保留原配置和实例。重要操作前备份存档；反馈时使用脱敏日志。

## 下载任务与拖拽导入

顶栏显示当前下载进度和速度，准备或校验阶段可能没有网络流量。箭头打开内嵌下载任务列表，也可从「更多 → 下载任务」进入。任务支持暂停、继续、取消和重试；提交安装结果时暂不可中断。取消保留已校验缓存，不会删除已安装内容。

拖入支持的文件时显示导入提示。整合包先确认名称和目标目录再入队；其他资源按类型导入当前实例，版本内容管理以该页选中实例为准。数据包需要选择具体存档，同名文件不覆盖。下载中可切换账号类型和浏览版本；登录与游戏启动需要先暂停下载。
