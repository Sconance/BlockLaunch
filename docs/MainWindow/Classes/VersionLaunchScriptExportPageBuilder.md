# VersionLaunchScriptExportPageBuilder

构造版本设置中的启动脚本导出卡片，并将导出动作委托给主窗口脚本生成入口。

- **主要入口：** `Build()`。
- **协作：** 使用 `VersionSettingsPageContext` 提供的实例键和通用控件工厂。
- **源码：** [`VersionLaunchScriptExportPageBuilder.cs`](../../../src/MCUGLauncher/MainWindow/Builders/VersionLaunchScriptExportPageBuilder.cs)。
