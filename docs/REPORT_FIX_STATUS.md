# 报告对应修复状态（0.22.3-codex）

本轮以 0.22.3-codex 为基础处理报告中的关键问题，保留蓝白 UI。原 0.22.3 与 0.22.3-fix 分支不改动；不发 Release。

## 已落地

- 下载/安装接回 Core：ContentService 搜索、版本筛选、必需依赖解析及事务安装，ResourceDownloads 的 SHA-512 校验与断点下载，删除重复 ModService。
- OperationCoordinator 接入持久队列：排队、暂停、继续、取消、失败重试、删除历史；退出期间中断的任务可在下次启动继续。目标实例与安装参数在入队时保存，不随页面选择变化。
- 右上角持续显示下载入口与当前下载进度；下载任务页面不再是占位提示。启动应用和启动游戏不增加进度条。
- 安装与导入入口：Fabric、Quilt、Forge、NeoForge 版本读取/安装；本地整合包通过 PackService 导入，排队后校验源文件未变。
- 运行游戏管理接 RunningGameRegistry：独立会话、离线身份去重、列表、单独关闭与默认取消的确认框；退出启动器不关闭游戏。
- 收藏接 ResourceBookmarkStore：搜索卡片心形按钮与收藏列表；下载时按当前实例重新解析版本。
- 存档保护接 SaveProtection/WorldArchives：当前实例备份、备份列表、恢复为新存档；不覆盖原存档，运行中的实例不能恢复。
- Java 管理接 JavaDiscovery.Scan；不再把所有 Java 都假标为 x64/未知版本。
- 旧 Core Preferences 模型完整保留到新配置，运行使用保留的网络设置与启动参数；新配置常用字段与保留模型同步。旧配置文件仍保留。
- 浏览请求从前端移回宿主，采用 Core 网络策略；移除页面 fetch，加入 CSP，社区请求保留独立超时。
- 固定画布改为自适应；960×640 下可滚动访问，1920×1080 填满窗口。记忆窗口尺寸与最大化状态。
- 服务器响应只更新卡片状态字段，保留输入焦点与菜单事件。所有服务器菜单均绑定，空实例和空模组详情有空态。
- 原生模式启动不显示演示数组；原型模组依赖/版本详情不冒充真实详情。CSS 合并，强调色变量改为 accent。
- AGENTS.md、可执行边界规则、新模块的协议检查与浏览器检查接入 CI。

## 不能视为已全部完成

- 实例克隆、完整卸载计划、实例/整合包导出升级、内容更新预览尚未全部恢复；OptiFine 安装未加入本次入口。
- 旧收藏与服务器文件的全面迁移、配置存储完全归一、版本扫描全部改用 Core 仍需继续。保留旧设置不等于已经恢复所有设置页面。
- app.js/host.js 的既有页面与协议绑定还没有全部拆成模块；新增任务/安装/游戏/收藏/存档各自独立。
- 旧版截图和少量原型说明还需整理，不能当作本分支功能验收证据。
- 微软/MUA 真实授权、真实 Minecraft 多开/退出、真实整合包与各加载器安装，以及 Windows 多 DPI，仍需人工验收。本次没有据此宣布正式发布。

- Debug/Release 解决方案构建，六组隔离检查：Auth/Mua/Download/Queue/Compatibility/WebBridge。
