# MCUG Launcher 0.22.3

这次更新把启动器的主界面、版本管理和下载链路一起重做，并开始接入群友内容。

## 亮点

- **主页重排**：去掉左侧栏，账号、启动、实例选择集中在一列；右侧是服务器、公告、推荐和语录。
- **版本管理重做**：版本内容管理改成横向分类 + 模组表格，支持更新、禁止更新、禁用、启动、删除；右上角可切换当前实例。
- **模组下载**：模组列表 → 详情 → 安装到实例，或下载到自定义目录。
- **社区内容**：群公告、群友推荐、群友语录、服务器状态。
- **公告配图**：管理员发布公告时可以选图；没有写入接口时保存在本机并标记为待发布。
- **数据源可切换**：公告 / 服务器 / 推荐 / 语录四个 URL 独立配置，可逐项测试。

## 下载

| 版本 | 文件 | 需要 |
| --- | --- | --- |
| 完整版 | `MCUGLauncher-0.22.3-Windows-x64.exe`（`dist/full`） | 无 .NET 依赖；需要 WebView2 Runtime |
| 轻量版 | `MCUGLauncher-0.22.3-Windows-x64-Lite.exe`（`dist/lite`） | .NET 8 Desktop Runtime x64 + WebView2 Runtime |

## 升级说明

- 首次启动会尝试导入 `%LOCALAPPDATA%\BlockLaunch\settings.json` 中的游戏目录、玩家名、Java、内存和服务器收藏。
- 新配置位于 `%LOCALAPPDATA%\MCUGLauncher\config.json`。
- 默认社区地址是示例仓库；发布前请在「设置 → 数据源」或 `Models/AppConfig.cs` 中替换成实际地址。

## 修复

- 修复 WebView2 在高 DPI 下内容缩小、四周留白的问题，恢复 1:1 CSS 缩放。
- 页面跳转改为单页路由，不再整页重载，消除按钮点击卡顿。
- 换成蓝白主题与新 Logo；修复窗口拖动、圆角与标题栏链接/文字拖拽问题。
- 设置页、下载分类、账号与版本设置中的占位操作现在会给出明确反馈，不再静默无响应。
- 接入正版 / MUA 登录；服务器、公告、群友推荐支持本机删除；修复语录切换抖动；下载筛选改为上下布局。
