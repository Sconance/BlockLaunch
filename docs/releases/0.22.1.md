# MCUG Launcher 0.22.1

本版汇总多游戏运行、启动加载优化、运行列表交互、进度展示调整，以及设置页面与代码结构优化。

## 多游戏运行与运行列表

- 支持同时运行多个独立实例，每个游戏分别记录进程、角色、运行状态和本次日志，可单独查看日志与请求关闭。
- 首页“运行中的游戏”可点击进入列表，显示当前运行的游戏数量与角色名。
- 单独关闭游戏时显示紧凑的二次确认，提示未保存的内容可能丢失；取消或按 Escape 不会关闭游戏。
- 同一实例允许更换离线 ID 后多开，相同身份仍防止重复启动；第二个会话不重写共享的语言与离线皮肤包配置。

## 启动与进度展示

- 启动恢复以本地数据为主，在线版本目录改为进入下载分类后按需加载，减少网络等待对启动页面的影响。
- 在线目录请求增加请求合并、超时、取消与失败重试状态。
- 移除启动器启动和游戏启动时的全局进度条，保留取消当前操作的入口。
- 下载进度统一放在标题栏右上角；下载任务列表保留文本状态、百分比、暂停、继续/重试与取消操作。

## 设置与菜单

- 顶部“更多”合并进“设置”，左侧采用与下载页一致的分类菜单。
- 分类涵盖启动设置、Java 管理、下载与网络、界面与背景、服务器收藏、存档保护、下载任务、任务与恢复、运行日志、诊断与反馈、关于与许可。
- 保留原有工具操作及日志、任务、诊断快捷入口；旧入口会跳转到对应设置分类。
- 保留栏目注册与图片图标接口；原 Settings/More 扩展分别显示在扩展设置和工具扩展组。注册新栏目不强制跳走或重建当前页面。

## 代码结构与维护

- 延续 0.22.0 / main 的功能域、独立视图与组合层结构，MainWindow 继续只承担窗口外壳职责。
- 运行会话控制器通过不依赖 WPF 的展示接口工作；WPF 视图负责展示与交互，日志读取、诊断与关闭操作由明确的依赖提供。
- 设置导航、视图、页面生命周期和栏目组装分离；页面按需创建，离开工具页面时清理 Java 搜索、服务器查询等生命周期。
- 外观、Java、服务器与存档表单拆到 Views/Settings，通过明确的状态与操作回调工作；网络复用独立 NetworkSettingsForm。
- 设置直接承载独立页面，旧弹窗入口复用同一页面，不再通过拆卸弹窗内容来嵌入。
- 设置路由使用命名页面与宿主引用，移除本次组装中对标签位置、按钮文字和控件树查找的依赖。
- 同步类型文档、开发说明、测试说明，并增加架构边界检查与标签重排后的导航检查。

## 下载与升级

- `MCUGLauncher-0.22.1-Windows-x64.exe`：完整版，内置 .NET 运行库。
- `MCUGLauncher-0.22.1-Windows-x64-Lite.exe`：精简版，需要安装 .NET 8 Desktop Runtime x64。
- `MCUGLauncher-0.22.1-Source.zip`：本版本标签对应的完整仓库源码，不包含用户账号、配置或游戏数据。
- `SHA256SUMS.txt`：上述三个附件的 SHA-256 校验值。

关闭启动器后替换 EXE；现有账号、配置和实例数据保留，账号协议与配置格式未改动。游戏仍需匹配版本的 Java，内嵌微软授权需要 WebView2 Runtime。
