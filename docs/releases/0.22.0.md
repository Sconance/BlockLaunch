## 变更摘要

- `Components/` 按 Accounts、Shell、Downloads、Resources、Instances、Launch、Experience、Bookmarks、Support 九个功能域重组；10 个控制器按职责改名（`Sketch`→`InstanceContent`、`Content`→`ResourceBrowser`、`Pack`→`Modpack`、`Stability`→`TaskRecovery` 等）。
- 补齐 `src/MCUGLauncher` 全部 142 个顶层类型的类文档，归档到 [docs/classes](../classes/README.md)，新增 `scripts/check-class-docs.py` 与 CI 检查。
- 文档体系整理：refactor 时代的对照、迁移与合并记录移入 [历史归档](../archive/branch_refactor/README.md)；新增 [合并到主分支前的说明](../MERGE_TO_MAIN.md) 与 [重构路线图](../../TODO.md)。
- 记录前后端分界评估结论与后续项；版本号保持单一来源，发版脚本按 `McugVersion` 命名产物。

## 兼容性

- 用户数据不变：存储目录 `BlockLaunch`、账号加密熵、JSON 字段名、实例与整合包格式均未修改。
- 菜单扩展接口不变：`LauncherMenuRegistry`、`LauncherMenuPage`、`LauncherMenuArea`、`LauncherMenuContext` 未改名。
- 类与目录调整属于内部实现，不影响用户行为与对外接口。

## 升级说明

关闭启动器后替换 EXE，账号、配置与实例目录保持不变。完整版内置 .NET 运行库；Lite 版需要 .NET 8 Desktop Runtime x64；两版都需要 WebView2 才能使用内嵌微软授权。
