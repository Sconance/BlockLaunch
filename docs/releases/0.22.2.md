# MCUG Launcher 0.22.2

## 主要变化

1. **资源搜索**：游戏版本改为可下拉选择和输入搜索；资源包、光影包隐藏加载器筛选。修复卡片心形按钮，支持直接收藏与取消收藏，不再误进入详情。
2. **下载与安装**：详情页收藏与更多操作移到左侧，右侧集中下载选项。“自定义下载”和“安装到实例”单选切换，任务固定所选实例目录、游戏版本、加载器和资源版本；数据包安装时选择目标实例内的存档。
3. **实例列表**：副标题只显示 Minecraft 和加载器版本，缺少可识别元数据时显示“版本未知”；分类标题整行可点击展开、收起。
4. **下载记录**：增加删除已结束记录和清空已结束下载记录的功能；保留下载文件，不删除正在运行、排队或暂停的任务。
5. **模组管理**：合并到“版本内容管理 → 模组”，旧入口跳转到统一页面。保留导入、启用/禁用、更新、移除、回退和目录入口，列表撑满剩余空间。
6. **启动提示**：启动按钮内显示简短状态与进度动画，已知进度显示实际百分比对应的进度条，其余阶段使用不定动画；结束后恢复按钮，不增加独立加载页面。
7. **代码维护**：延续独立视图、明确依赖和组合层结构；安装协调与 WPF 分离，复用已有任务队列和模组管理逻辑，同步类型文档及架构边界检查。

## 兼容性

- 保留现有账号、配置、实例和下载文件，继续提供完整版与 Lite。
- 保留菜单扩展和图片图标接口，同时保留此前的低分辨率图标优化。

## 验证

- 24 组本地回归检查及 GitHub CI 通过，构建 0 警告、0 错误。
- 自动交互与界面渲染检查通过；本轮未完成原生鼠标验收，也未重跑真人授权与完整游戏版本矩阵。

附件包含完整版、Lite 和源码 ZIP。完整版内置 .NET 运行库；Lite 需要 .NET 8 Desktop Runtime x64。关闭启动器后替换 EXE 即可升级。
