# test 与 refactor 的结构比较（合并前快照）

> 历史归档：本文记录 refactor 时期的一次性过程，`refactor` 分支已废弃。现行文档见 [开发导览](../DEVELOPMENT.md) 与 [合并到主分支前的说明](../MERGE_TO_MAIN.md)。


> 本文拍摄于合并前（2026-10-28）：`test` 在 `0eaf5ec`、`refactor` 在 `db0ab6a`，版本仍为 0.20.2。随后 `refactor` 已作为第二父提交并入 `test`（合并提交 `145bf37`），版本统一为 0.21.0。本文保留为结构对比的历史依据，现行关系、迁移去向与退役文档见 [refactor 分支整合记录](REFACTOR_INTEGRATION.md)。

窗口拆分以 `test` 的 `32a3ad1` 为起点；当时从 `156208e` 继续，参考远程 `refactor` 的 `db0ab6a`，只修改 `test`。两者已有独立提交历史，当时没有执行整分支合并、版本升级或 Release 发布。

| 方面 | 当时的 test | refactor 参考快照 |
| --- | --- | --- |
| 原生窗口 | 保留精简的 MainWindow shell | 仍有 MainWindow partial 功能文件 |
| 页面布局 | 九个独立 XAML 视图与强类型动作路由 | 较多页面通过 UI partial、构建器和对话框组件组织 |
| 显式依赖 | 原六个独立模块之外，内容更新及新抽取的内容管理、启动设置、导出对话框也只接收所需数据和操作 | 部分控制器接收明确参数，部分仍接收 MainWindow |
| 复用组件 | 11 个完整文件与参考提交一致；其余同名组件做依赖适配，详见延续记录 | 固定参考实现来源 |
| 展示模型和表单 | Models、Views/Forms、Views/Shared 与控制器分开 | 已有 Models、Builders、Views 等分类 |
| 版本设置细分 | 五个独立页面、独立视图与身份编辑器；页面只接收当前实例数据和明确操作 | 已有专用页面构建器，但页面上下文仍可以访问 MainWindow |
| 耦合限制 | 其他应用协调模块仍使用 LauncherWorkspace | 仍有窗口 partial 与共享窗口状态 |
| 自动检查 | test 推送触发构建；额外检查 UI 边界、参考代码一致性、组件与收藏流程 | 直接推送只匹配 main，已有基础检查 |
| 版本 | 当时保持 0.20.2，不发布正式程序 | 快照标记 0.21.0；合并后统一由 `Directory.Build.props` 控制 |

当时吸收了小组件与明确依赖的做法，同时保留 test 的窗口/独立页面边界。版本号大小不能用来判断结构优劣。

版本设置已细化为五页，内容管理、全局启动选项、实例导出也已独立。后续适合收窄实例概览、资源工作区、任务协调与启动协调的依赖（该计划继续记录在 [重构路线图](../../TODO.md)）。不要为消除一个工作区参数，换成包含整个工作区所有成员的巨型接口。

准确的原始文件复用清单、依赖适配理由与保留的 test 修复见 [refactor 延续记录](REFACTOR_CONTINUATION.md)。

当时对 test 执行构建和回归检查，未对 refactor 重新执行完整验证；该记录不用于断言两侧运行稳定性优劣。真实微软/MUA 人工授权及完整游戏启动矩阵仍需单独验收。
