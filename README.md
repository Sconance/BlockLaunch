# BlockLaunch

Minecraft Java 启动器的私有历史版本归档。

## 下载与运行

- [最新版本](https://github.com/Sconance/BlockLaunch/releases/latest)
- [全部历史版本](https://github.com/Sconance/BlockLaunch/releases)
- 0.3.0 及之后：下载对应的 `Windows-x64.exe` 直接运行（需要已安装对应运行库）。
- 0.1.0、0.2.0：下载 `Windows.zip`，完整解压后运行其中的 `BlockLaunch.exe`，保留同目录依赖文件。
- 每版附带 `SHA256SUMS.txt`，用于核对下载文件完整性。Guide 文档为中文说明。

## 源码与版本说明

对应历史源码请下载各 Release 手动附带的 `BlockLaunch-版本号-Source.zip`。本仓库标签用于发布归档，GitHub 自动生成的 Source code 压缩包仅包含标签所指向的仓库内容，并非上述历史源码附件。
